== Общие правила

* Позиции заказов (билеты и проживания) учитываются в любом статусе заказа, если в задании явно не сказано иное.
* Значения натуральных ключей (email, номер паспорта, номер рейса, коды IATA, названия) выводите и сравнивайте ровно в том виде, в каком они даны в исходных данных raw; не преобразуйте их при миграции.
* Средние и денежные суммы, полученные делением/умножением на процент, округляйте до 2 знаков (ROUND(…, 2)); сравнения («выше средней», «лучший») выполняйте по неокруглённым значениям.
* Если показатель не определён (нет ни одной строки для усреднения), выводится NULL, а не 0 — кроме колонок, где задание явно разрешает 0.
